# 0.3.0 安全整改记录

> 历史版本记录。当前能力见 [基础控制说明](CONTROLS-0.3.2.md)，当前安全结论见 [0.3.3 审查](AUDIT-0.3.3.md)。

日期：2026-11-03。与 0.2.6 审查逐项对应。修复不等于安全认证；本次没有实际门锁或其他真实设备写入测试。

| 原问题 | 本版处理 | 状态/剩余限制 |
|---|---|---|
| S01 内置共享应用密钥 | 从源码/新 ZIP 删除两项 secret；仅从本机 YAML/!secret 获取；无默认值回退；缺失时明确终止配置/加载 | 打包泄漏已处理。厂商授权、专用公共客户端、历史披露轮换仍需负责人处理；服务端刷新协议仍要求 URL 查询参数，不能擅自改成不兼容协议 |
| S02 原始服务权限 | 使用 HA admin-service，额外拒绝无用户上下文 | 原生 HA 服务运行时已测试管理员/非管理员/无身份；普通实体动作走 HA 标准权限 |
| S03 敏感属性自动控制 | 产品键 + 属性 accessMode/dataType/specs 固定白名单，定义变化拒绝；门锁无写权限 | 当前两种空调与一种锁模型，不能宣称所有产品支持；冰箱/洗衣机暂为有限只读识别 |
| S04 重定向令牌外传 | allow_redirects=False，3xx 全拒绝，HTTPS 域名/端口白名单 | 合成回归验证；未测试真实恶意云端 |
| S05 错误正文泄漏 | HTTP/JSON/连接/业务错误不回显正文、URL或云端 msg；更新日志不含设备 ID | 合成秘密标记测试通过；HA 和反向代理自己的日志规则不由本插件全面控制 |
| S06 诊断脱敏遗漏 | 改为结构字段白名单：成功状态、计数、轮询间隔；不导出 device/status/error/title/options/标识 | 嵌套及未知敏感字段测试通过 |
| S07 输入校验 | 写入前验证布尔、枚举、数值范围、步长与有限值；拒绝文本/结构/未知类型 | 原生 coordinator 测试确认拒绝路径没有云调用 |
| S08 TLS 可关闭 | 请求固定 ssl=True，HA session 固定校验；旧 false 设置迁移 true | 保留兼容构造参数但其 false 值不再生效 |
| S09 QR URL | 仅允许所选账号中心同源 HTTPS，拒绝非标准端口/凭据/Markdown危险字符；图片 no-referrer | CN/FR 真实取码通过；未允许未经核对的 CDN；图片仍依赖厂商来源及其浏览器重定向行为 |
| S10 请求配额 | 默认30秒、最低15秒；旧过快选项改30；429 尊重有界 Retry-After，连接/5xx指数退避 | 间隔仍需厂商确认；二维码新 flow 独立实例，未做跨 flow 全局配额；无盲目命令重试 |
| S11 前端/CI | 移除全局 prototype 修改，改作用于对话框的观察器；Actions 固定已查询的 SHA，增加 Dependabot | 前端仍依赖私有 DOM，只验证当前 HA；Core 仍应采用官方接受的原生方案。GitHub CI 尚未执行 |
| S12 支持声明 | HACS 最低版本改已验证的2026.9.4；删除自行填写的 bronze | 不代表官方审核或全部地区/型号通过 |

JWT 无法解析时改为1小时保守刷新窗口，而非30天；仍依赖服务端实际失效返回，尚未取得稳定 expires 字段契约。token 仍存在 HA config-entry 存储中，!secret 也不是加密。云端撤销/数据保留取决于厂商。现有同国单账户限制仍在。

## 验证

本地 pytest（含新安全回归）、Ruff、Black，以及 HA 2026.9.4 Python 运行时的独立服务/写入/实体注册迁移测试。原生测试使用模拟账户与云端函数，未操作真实设备。二维码脚本通过模拟浏览器测试，以及在当前真实 HA 页面仅替换前端脚本的桌面/手机、刷新、未扫码继续测试；这不等于新版后台已经部署。

真实 CN/FR 取码与严格 HTTPS 校验通过；已配置账户的设备列表复测遇到连接错误，不能声称完整新版云端联调通过。既有物模型只用于生成审核配置，未把真实账号 token、状态或家庭标识打进包。

尚未执行完整依赖漏洞扫描、官方 Core 测试覆盖或官方收录流程。共享密钥授权与厂商公共认证方案必须在公开发布前确认。旧版 ZIP/此前交接包没有自动删除，仍含旧凭据，请停止继续分发；若已公开，应按厂商流程处置/轮换，并清理公开仓库历史。
