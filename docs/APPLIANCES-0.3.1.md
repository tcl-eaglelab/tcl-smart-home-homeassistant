# 0.3.1 国内冰箱、洗衣机显示修复

> 历史版本记录。当前能力见 [基础控制说明](CONTROLS-0.3.2.md)，当前安全结论见 [0.3.3 审查](AUDIT-0.3.3.md)。

0.3.0 的产品能力规则没有覆盖本次国内账号返回的冰箱与洗衣机模型，分类判断也遗漏了 RF、DW、IWD 类别编码。没有可创建的实体时，HA 不会为这些设备建立设备页面。

## 本次修改

- 每台云端列表中的设备都创建默认启用的“云端在线”诊断实体，即使物模型为空或具体功能尚未适配，也能显示设备。离线显示为断开；云端没有在线标记时显示未知；同步失败时显示不可用。
- 增加 31 种冰箱、29 种洗衣机及 1 种集成洗衣机物模型的只读能力规则，精确匹配产品和属性结构。
- 冰箱显示冷藏/冷冻/变温室设定温度、实际温度和门状态，具体项目取决于该型号提供的属性。不会把设定温度标为实际温度。
- 洗衣机显示运行状态、程序、阶段和剩余时间；集成洗衣机另外显示烘干相关状态。
- 剩余时间明确标注“含预约”。云端单位为 NA 时不臆测分钟；明确返回 min 的烘干时间才标注分钟。摄氏符号 ℃ 统一为 °C。
- 故障代码作为默认停用的诊断实体，需要时在实体设置中启用。
- 国内使用中文功能名称，海外使用英文名称。新增属性均不开放控制，云端标记 rw 也只读展示，原始属性服务同样不能写入。
- 首次物模型拉取失败后，60 秒后允许重试，正常模型继续使用原有缓存周期。

## 查看方式

进入 **设置 → 设备与服务 → TCL Smart Home → 国内账号 → 设备**，搜索“冰箱”或“洗衣机”。状态出现在“传感器”区域，云端在线信息出现在“诊断”区域。已有账号不需要重新扫码；升级后重启 HA，浏览器刷新页面即可。

“未知”表示还没有有效属性值，不等同于设备未发现或离线。本次抽查部分设备的状态接口返回空对象，因此实体保留但没有数值；集成洗衣机和部分冰箱已收到有效数据。等待设备上报或在 TCL App 查看同一设备，再等下一次同步；不要把缺失数值替换为零。

## 验证边界

110 项离线测试通过；HA 2026.9.4 运行环境中的权限、写入校验与注册表迁移测试通过；本机已安装 0.3.1 并重启。国内接口的 74 台设备全部建立设备页面，其中冰箱 31 台、普通洗衣机 29 台、集成洗衣机 1 台。海外账号仍正常加载。浏览器检查冰箱和集成洗衣机页面通过。

验证没有向真实设备发送控制指令。型号适配依据物模型语义和云端读取结果，不代表所有型号均已完成实机全流程验证。原有应用密钥配置要求及安全限制见 [安全说明](SECURITY-0.3.0.md)。
